# Reflection

1. After moving files, the links to other HTML pages and the CSS stopped working because the paths pointed at the old locations. I used relative paths and root relative paths to direct to the correct subfolders.

2. I chose relative paths on index.html as well as files week1.html, week2.html, week3.html, week4.html. I used root relative for week5.html and week6.html. I decided to use relative paths for most files because it works better for me personally in terms of organization.

3. One risk of displaying an image from someone else's server is that at any point the owner can delete, move, rename, or replace the image, which would break the image on my own page.

4. The AI did a great job at making a visually appealing site and creating the foundation of the HTML and CSS.
